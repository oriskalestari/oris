Perangkat Utama

Peralatan Perakitan Kabel LAN

4 Komponen vital yang dibutuhkan untuk pembuatan kabel jaringan UTP dan pengujiannya.

Tang Crimping

Alat khusus untuk mengunci pin emas konektor RJ45 ke urutan kabel UTP serta memotong dan mengupas jaket pelindung kabel.

Kabel UTP (Cat5e/Cat6)

Unshielded Twisted Pair yang berisi 4 pasang (8 helai) kawat tembaga terpilin berwarna sebagai media transmisi data jaringan.

Konektor RJ-45

Konektor standar 8-pin transparan yang dipasang di kedua ujung kabel UTP agar dapat dicolokkan ke port Ethernet LAN.

LAN Tester

Alat penguji sinyal berbasis indikator LED 1-8 untuk memverifikasi apakah sambungan pin pada kedua ujung kabel terhubung presisi.

Straight-Through Cable

Kedua ujung kabel menggunakan standar urutan yang sama (B - B atau A - A). Digunakan untuk menghubungkan 2 perangkat berbeda jenis, seperti PC ke Switch/Router.

Cross-Over Cable

Ujung 1 menggunakan standar T-568A dan Ujung 2 menggunakan T-568B. Digunakan untuk menghubungkan 2 perangkat yang sejenis secara langsung (misal: Laptop ke Laptop tanpa Switch).

Langkah Kerja

Panduan Crimping & Pengujian LAN Tester

4 Langkah praktis merangkai hingga memastikan konektivitas jaringan.

1

Kupas Jaket Kabel

Kupas pelindung luar kabel UTP sepanjang ± 2 cm menggunakan pemotong tang crimping. Berhati-hatilah agar serat tembaga dalam tidak terputus.

2

Urutkan & Ratakan

Luruskan ke-8 helai kabel kecil, susun sesuai pola warna standar (T568B/T568A), lalu potong rata dengan tang crimping agar simetris.

3

Masukan ke RJ-45 & Press

Dorong susunan kabel hingga menyentuh ujung konektor RJ45. Masukkan konektor ke port crimping lalu tekan tang dengan kuat hingga berbunyi 'klik'.

4

Uji Sinyal LAN Tester

Colokkan kedua ujung konektor ke LAN Tester master & remote. Nyalakan switch dan perhatikan urutan kedipan lampu indikator LED 1-8.

Konfigurasi Jaringan

Koneksi 2 Laptop & Sharing File Folder

Langkah setting alamat IP statis dan berbagi direktori file tanpa koneksi internet.

Laptop A (Pengirim / Server)

1. Atur IP Statis:

  • IP Address: 192.168.1.1
  • Subnet Mask: 255.255.255.0
  • Default Gateway: (Kosongkan)

2. Pengaturan Advanced Sharing:

Buka Control Panel > Network and Sharing Center > Advanced sharing settings.

Turn on Network Discovery

Turn on File and Printer Sharing

Turn off Password Protected Sharing (Optional)

3. Bagikan Folder (Sharing):

Klik kanan Folder yang ingin dibagikan > Properties > Tab Sharing > Klik Share... > Tambahkan "Everyone" dengan Permission "Read/Write".

Laptop B (Penerima / Client)

1. Atur IP Statis (Satu Subnet):

  • IP Address: 192.168.1.2
  • Subnet Mask: 255.255.255.0
  • Default Gateway: 192.168.1.1

2. Pengujian Koneksi (Ping Test):

Buka Command Prompt (CMD), lalu ketikkan perintah berikut untuk memastikan sinyal terhubung:

ping 192.168.1.1

3. Akses Folder Terbuka:

Tekan tombol Win + R, masukkan alamat berikut untuk membuka folder Laptop A:

\\192.168.1.1
